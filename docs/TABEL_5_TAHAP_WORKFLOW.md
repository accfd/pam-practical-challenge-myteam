
## 🎙️ Formula Talking Points ke Dosen Penguji (1 Menit Demo)

> *"Assalamualaikum wr. wb. Selamat pagi/siang Pak/Bu.  
> Pada praktikal challenge ini, saya membangun **Workflow Lengkap Portofolio Riwayat Pengalaman Mahasiswa (FR-05)** dengan arsitektur MVVM murni:
>
> 1. **Input / Event:** Dimulai saat pengguna mengetuk tombol **Tambah Pengalaman**, mengisi 4 kolom input yang dikontrol `TextEditingController`, lalu menekan tombol **Simpan Pengalaman**.
> 2. **State:** Dikelola secara terpusat di `PengalamanViewModel` menggunakan `ChangeNotifier`. Ketika list masih kosong, UI merender **Empty State**. Saat ada data baru, `notifyListeners()` otomatis memicu `ListenableBuilder` untuk merender ulang antarmuka menjadi **ListView Kartu**.
> 3. **Validation:** Memiliki 2 lapis pengamanan: Validasi form (nama wajib & minimal 3 karakter, peran wajib, tahun wajib berupa angka rentang 2000–2026), serta validasi anti-duplikasi kombinasi nama, peran, dan tahun.
> 4. **Feedback:** Memberikan kepastian visual di setiap titik: border merah saat salah input, loading spinner 'Menyimpan...' saat diproses, modal pop-up centang hijau saat berhasil, dan SnackBar hijau di halaman utama.
> 5. **Navigation & Result:** Menerapkan navigasi 2 arah menggunakan `Navigator.push<PengalamanModel>` yang meneruskan data lama ke depan, serta `Navigator.pop(context, newPengalaman)` yang membawa objek data baru kembali ke halaman utama untuk langsung ditampilkan."*
